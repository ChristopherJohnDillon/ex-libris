# Ex Libris v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A self-hosted home book catalogue in one Docker container: a phone barcode scanner, editions, covers, browse, stats, and a read-only public view on its own port.

**Architecture:**
- One Python process runs two FastAPI apps: **library** on 8080 (everything) and **public** on 8081 (read-only routes only), plus an in-process task loop.
- All domain logic lives in `exlibris/core` (no web imports) over one SQLite database in `/data`.
- Templates are Jinja. Front-end JS and CSS are plain files in `exlibris/web/static`, with ZXing and ECharts vendored.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, Jinja2, httpx, Pillow, python-multipart, SQLite FTS5, pytest, Docker (multi-arch), GitHub Actions.

**Spec:** `docs/specs/2026-09-26-ex-libris-v1-design.md`

## Global Constraints

- **Data** lives only under `EXLIBRIS_DATA` (default `/data`): `library.db`, `covers/`, `cache/`, `backups/`.
- **Settings** (env, all optional): `EXLIBRIS_TITLE` (default "Our books"), `EXLIBRIS_PUBLIC` (default `on`), `EXLIBRIS_OPENLIBRARY_CONTACT`, `EXLIBRIS_AI_URL` / `EXLIBRIS_AI_MODEL` / `EXLIBRIS_AI_KEY`, `EXLIBRIS_GOOGLE_BOOKS` (default `on`), `TZ`.
- **Ports:** 8080 library, 8081 public. The public app registers GET routes only.
- **Public fields only on 8081:** `id, title, authors, year, format, publisher, isbn, cover_url, genre, series, series_index, pages`.
- **No reading status or ratings.** No login. No CDN: vendored JS and bundled fonts; CSP `script-src 'self'`.
- **Open Library:**
  - User-Agent `ex-libris/<version> (+https://github.com/ChristopherJohnDillon/ex-libris)`, plus the contact if set;
  - paced at 1 request/s, or 3/s with a contact;
  - editions and works cached indefinitely, authors for 7 days.
- **Writes on 8080:** JSON or an `HX-Request` header, plus the same-origin check.
- **Idle memory** under 150 MB. Image for linux/amd64 and linux/arm64, running as a non-root user.
- **Nothing identifying the maintainer's setup** (`scripts/check_clean.py` must pass). Commit author "Ex Libris contributors".

## Review Focus

1. **Title-only books** (no ISBN, author or year) in every view, the stats, CSV export/import and the public view. Covered by a fixture shelf in Task 3's tests.
2. **Camera unavailable** (http, permission denied, iOS without BarcodeDetector): the scanner falls back to typing an ISBN with a clear message. Task 6 test (the page contains the fallback form and the http message).
3. **Open Library down or slow:** looking up an ISBN returns a clear error the page shows ("Open Library didn't answer — add it by title") and nothing crashes. Task 5 tests with the HTTP client mocked to raise.
4. **A first run on an empty `/data`** (fresh volume, non-root user): the app creates its folders and the database, and the home page shows the welcome text. Task 9 container smoke test.
5. **Hostile stored text** (Open Library titles and authors containing HTML): escaped in templates, browse JS and chart tooltips. Task 7 test with `<img onerror>` in the author and format.

### Task 2: Books core: add, edit, delete, search, editions, CSV

**Files:** Create `exlibris/core/books.py`, `tests/test_books.py`

**Interfaces:**
- `add(book: dict) -> dict` (raises `Duplicate(title_of_existing)`)
- `update(id, changes: dict) -> dict | None` (raises `ValueError` on bad input, `Duplicate` on an ISBN clash)
- `delete(id) -> bool`, `get(id) -> dict | None`
- `search(q="", limit=100000, public=False) -> {"total", "books"}`: FTS; public mode matches `{title authors isbn publisher}` only; order `added_at, id`
- `isbn13(text) -> str | None`, `is_isbn13(s) -> bool`
- `public_row(row) -> dict`: public fields; `cover_url` becomes `/cover/<name>`
- `to_csv() -> str`, `import_csv(text, commit=False) -> {"new": [...], "duplicates": [...], "errors": [...]}`
- `authors_of(row) -> list[str]` (split on ", "; rejoin "Jr.", "Sr.", "II", "III" onto the previous name)
- `locations() -> [{"name", "n"}]`, `overdue_loans(today, days=60)`
- `norm_format(s)`: an all-lowercase format gets title case

**Steps:**
- [ ] **Tests:**
  - editions: two ISBNs of one work → two rows, and the same ISBN → Duplicate;
  - no ISBN plus the same work key → Duplicate;
  - update coerces numbers (`"c. 1965"` → ValueError), a blank title → ValueError, ISBN-10 → 13, a lowercase format gets title case;
  - search prefix-matches "harr pot", and public search ignores notes;
  - "Walter M. Miller, Jr." → one author;
  - CSV round trip; import previews without writing, and `commit=True` writes new rows and skips duplicates;
  - loans over 60 days.
- [ ] Run: fail. Implement; pass; commit `feat: books core`.

### Task 4: Covers, AI, backups, tasks

**Files:** Create `exlibris/core/covers.py`, `exlibris/core/ai.py`, `exlibris/core/backup.py`, `exlibris/core/tasks.py`, tests for each

**Interfaces:**
- `covers.save_upload(book_id, data: bytes) -> url | None`: Pillow; refuses non-images and images under 60 px; max 600 px; never enlarges.
- `covers.find(book, json_get, image_get) -> (url, source) | (None, None)`, `covers.fill_missing(limit=20) -> str`
- `ai.enabled() -> bool`, `ai.choose_genre(title, authors, subjects, post=None) -> str | None` (the 15 genres; off-list → "Other"; empty → None), `ai.fill_genres(limit=40) -> str`, `ai.fun_facts(facts, post=None) -> str | None`
- `backup.snapshot(now=None) -> Path` (dated db + csv in `backups/`, integrity-checked, rollback journal, 30 days kept, the newest kept), `backup.zip_bytes() -> bytes`
- `tasks.run_forever(stop: threading.Event)`: covers every 6h, genres every 2h (if AI), backups daily at 03:00 local, series backfill hourly; each step wrapped so one failure never stops the loop.

**Steps:**
- [ ] **Tests:**
  - Pillow: accepts a 100×150 image and refuses a 20×20 or non-image;
  - cover order (Google by ISBN before the OL work) with fakes, a placeholder refused, tried once;
  - AI mapping (exact, case, sentence, `<think>`, off-list, empty, exception) and a manual genre never touched;
  - backup: files present, integrity ok, journal mode delete, prune keeps the newest, the zip contains the db, csv and covers;
  - a task-loop step that raises still lets the next run.
- [ ] Run: fail. Implement; pass; commit `feat: covers, optional AI, backups, background tasks`.
